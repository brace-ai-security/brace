# Explicit source-contradiction controls

Two constructed report controls test unambiguous errors: a manifest claimed to
contain `sensitive: true` when it does not, and a corrected GET path claimed to
lack its visible ownership check. Both critical targets were detected by a fresh
source grader. These are constructed controls, not two naturally occurring model
reports. An independent audit checked their gold labels separately.

See [the combined gate and limits](../2026-10-25-mcp-source-calibration/README.md).
Inputs, labels, raw grades and derived checks remain in this directory.
