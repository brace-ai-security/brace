BRACE Resources

The agent-security ecosystem, mapped to BRACE

Resources for putting BRACE’s controls in place. Use the standards and threat models to understand risks. Use the reference designs to see ways to build. Use the software components to build and test your controls. Each entry is tagged with the BRACE concern it serves.

How to read this. Tags show the BRACE concern an item most relates to: Build-time Run-time Agent Config Ecosystem Observability Governance. Status flags: Open source Commercial Free Emerging Deprecating.

Source review: 2026-09-16; sources rechecked 2026-09-30. See the scope, findings, and verification limits. Listing is not endorsement. This field changes fast, so check an entry’s status before you rely on it. Know something we should add? Suggest a resource.

Open-source building blocks

The primitives you assemble BRACE-level controls from.

Identity & attribution → Agent

SPIFFE / SPIRE

CNCF-graduated workload identity — short-lived cryptographic SVIDs so agents authenticate without long-lived secrets. The foundation an agent identity chains from.

AgentObservabilityOpen source

IETF WIMSE draft — AI Identity Management System

A working-group Internet-Draft on agent identity, authentication, and authorization, not an RFC. It replaced draft-klrc-aiagent-auth in September 2026. This link does not independently substantiate other agent-passport or identity proposals.
