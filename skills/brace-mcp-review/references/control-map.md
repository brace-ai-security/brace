# MCP control and research map

Baseline: BRACE's [2026-10-22 review](https://braceframework.org/RESEARCH-2026-10-22.md)
and [checklist](https://braceframework.org/CHECKLIST.md). These links provide context;
the direct primary sources below remain usable when only this skill folder is installed.
BRACE IDs map findings to existing controls; the topic names here are not new checklist IDs.

## Enabled extensions and legacy paths

- **Tasks:** owner-authorize status/results/list/cancel and durable handles after
  reconnection. Cancellation is cooperative; independently verify cessation of effects.
- **Skills over MCP:** read the [extension](https://modelcontextprotocol.io/extensions/skills/overview).
  Inspect origin-bound manifests, file-set/digest/size checks, protected caches,
  changed-approval invalidation, dynamic content and nested activation consent.
  A matching digest establishes consistency, not safety or user authorization.
- **Apps:** read the [host specification](https://apps.extensions.modelcontextprotocol.io/api/documents/overview.html).
  Inspect iframe sandbox/CSP, bridge messages, resource origins and UI-initiated
  calls at the host. A gateway cannot prove those browser controls.
- **Auth extensions:** distinguish stable Enterprise-Managed Authorization from
  draft Client Credentials using current [extension status](https://github.com/modelcontextprotocol/ext-auth).
  Adoption is optional; compatible authentication does not prove business-task approval.
- **Older enabled paths:** inventory sampling, roots, legacy sessions and HTTP+SSE
  as implemented. Apply their negotiated revision and ownership checks; deprecation
  neither disables them nor proves their controls.
